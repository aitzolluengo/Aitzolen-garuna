# Rutinas diarias

# 🕐 Rutinas Diarias

> Sistema simple de rutinas para estructurar el día sin rigidez.

---

## Mañana (10-15 min)

```
☀️ Al despertar — antes de mirar el móvil
→ Tres líneas libres de lo que tengas en la cabeza (vaciado mental)
→ Lista de tareas del día con •
```

---

## Después de comer (15-20 min)

```
🚶 Paseo sin rumbo
→ Sin auriculares
→ Sin mirar el móvil
→ Dejar que la mente divague
```

**Por qué funciona:** corta el día en dos, ayuda a la digestión, evita el bajón de tarde. Las tardes rinden más.

---

## Noche (5-7 min)

```
🌙 Antes de dormir
📅 Fecha

→ ¿Qué pasó? (2 líneas)
→ ¿Cómo estoy? (2 líneas)
→ Una cosa para mañana
→ Migrar tareas no completadas (> o <)
```

---

## Ejemplo de día completo

```
-- Mañana --
No tengo ganas de levantarme. Hoy toca reunión y no me apetece nada.
Hace frío. Quiero café.

• Revisar correos
• Llamar a aita
* • Entregar informe

-- Después de comer --
[paseo 20 min, sin móvil]

-- Noche --
📅 18 mayo

→ ¿Qué pasó? La reunión fue mejor de lo esperado, nos reímos bastante.
   Paseo después de comer, vi un gato en un portal y estuve un rato mirándolo.

→ ¿Cómo estoy? Cansado pero con la cabeza más despejada que ayer.
   Creo que el paseo ayudó, noto la diferencia.

→ Una cosa para mañana: llamar a aita. Llevo días aplazándolo.
```

---

## Reglas

1. **Nunca saltes dos días seguidos** — uno se perdona, dos crean el hábito de no hacerlo
2. **Si no tienes tiempo, una línea basta** — la consistencia vale más que la cantidad
3. **El paseo es inamovible** — es el ancla del sistema
4. **Sin auriculares en el paseo** — si no, no cuenta
